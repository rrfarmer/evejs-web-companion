# Current-pilot Ready Fit

The Neocom **Ready Fit** action opens an ordinary cockpit window for the
currently held pilot. Review, Replenish Consumables and Provision Ship consume
the shared engine and held authority; there is no pilot selector or Factory
acquisition. Definition provider and physical item source remain separate.

The panel captures its cockpit props and request options. Pilot/token changes,
ship/location/transition changes and window disposal retire accepted reviews
and late replies. Server-side held-generation fencing remains authoritative.

Unsupported or destructive plans refuse confirmation. An exact equipment match
requires no fitting changes.
