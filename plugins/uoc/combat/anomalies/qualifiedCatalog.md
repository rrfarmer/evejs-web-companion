The bundled `qualifiedCatalog.json` is derived from the pinned EveJS content packs `evejs.combat-anomalies/1.4.4` and `evejs.drone-anomalies/1.4.0`, `npcProfiles/data.json` and `itemTypes/data.json`; source file SHA-256 values are embedded in the asset. The WC74 reference is `src/pveAnomalyCatalog.json` at 213da333, also hashed in the asset.

An entry is included only when the WC74 and pack dungeon ID and difficulty agree, the pack has a single room and no connections, completion is `destroy_all_encounters` with `completeObjectiveOnEncounterClear`, every authored NPC spawn has an explicit profile ID whose pinned profile resolves to its exact type ID, and every type maps to an NPC category/group projected as a ship. Any blocking structure or unresolved profile excludes the entire template. The 89 included entries are source-qualified, not live-qualified; the other 109 require proof of profile fallback and are not treated as empty encounters. Runtime uses the native `room:entry` keeper identity (room 0), and the existing exact instance, encounter completion and custody fences remain authoritative.
