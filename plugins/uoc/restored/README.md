# UOC views

This directory contains the Svelte center views, their styles, and the adapters that connect those views to operations and held sessions. The route tree and browser entry live in the page directory. Backend routes and hosted runs live in the UOC plugin outside this directory.

Adapters use the public WC Plugin API and retain the checks for verified pilot ownership, destination and fitting identity. Training and Provisioning show the candidate fitting assessment separately from the native equipment readback.
